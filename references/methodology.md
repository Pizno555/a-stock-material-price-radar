## 目标与边界

用最近一段时间内可追溯的价格、供需、来源和市场数据，衡量材料涨价线索的“发酵程度”。评分用于排序和研究优先级，不是收益预测。

当前评分方法版本为 `2.0.0`：消息密度 20、来源质量 25、价格验证 25、供给约束 20、A 股异动 10。

默认观察近 10 个自然日，最多输出 30 条。只有股票异动而没有材料价格或供给信号的主题不进入候选池。

## 信源分级

| 等级 | 定义 | 常见示例 |
|---|---|---|
| S | 具有正式披露责任或原始统计责任的材料 | 监管/交易所、政府统计、公司正式公告、公开合同或结算数据 |
| A | 可追溯的第一方或专业价格/行业材料 | 企业官网/IR、行业协会、海关、权威价格机构、上下游实名确认 |
| B | 有采编或数据责任且可识别原始线索的二手材料 | 主流财经媒体、成熟数据服务商 |
| C | 解释性或预测性材料 | 券商研报、咨询机构、专家观点、行业媒体分析 |
| D | 仅能作为发现线索 | 匿名爆料、社交媒体、无原始链接的聚合内容 |

同一转载链、同一发布者的重复内容或同一原始事件只算一个独立来源。证据等级衡量来源质量，不等于事件强度；企业调价函可以是高等级来源，但价格是否落地仍由“价格验证”单独评分。

## 候选发现与去重

1. 以化工、金属与资源、半导体/电子材料、PCB、锂电、能源、先进材料为发现种子。
2. 搜索涨价、提价、报价上调、成交价、价格指数、库存、开工率、检修、停产、配额、出口限制、交期、订单等组合词。
3. 统一材料别名、化学式、英文名、产品规格和产业链简称。
4. 为每条证据设置唯一 `evidence_id`；评分字段通过 `evidence_refs` 引用它。未绑定的叙述或数值不计分，引用内容必须直接支持对应维度事实。
5. 为每条证据设置 `independence_group`。转载稿使用同一个组；不同机构独立采集或不同原始文件使用不同组。
6. 为同一调价函或同一停产事件复用同一 `event_id`，避免消息密度重复计数。
7. 至少保留一条在监控窗口内、可定日且绑定到价格或供给维度的证据，否则剔除候选。

## 五维评分

### 1. 消息密度：20 分

消息密度 = 独立事件数量（12）+ 来源类型多样性（4）+ 近期加速度（4）。

独立事件数量按窗口内去重后的 `event_id` 计分：

| 数量 | 分数 |
|---:|---:|
| 0 | 0 |
| 1 | 2 |
| 2 | 5 |
| 3–4 | 7 |
| 5–7 | 10 |
| ≥8 | 12 |

来源类型按数据契约允许的不同 `source_class` 数量计分：0/1/2/3/≥4 类分别为 0/1/2/3/4 分。未知类别不计分。

加速度比较窗口最近 30% 天数与此前 70% 天数的日均独立事件数。比值 `<0.8`、`0.8–<1.2`、`1.2–<1.5`、`1.5–<2`、`≥2` 分别得 0/1/2/3/4 分。前段为 0、近期有事件时得 4 分；缺少可解析日期时得 0 分并记录缺口。

### 2. 来源质量：25 分

从三个最强、相互独立的信源计算：

- 最强来源基础分：S/A/B/C/D = 16/13/9/5/1。
- 第二个独立来源加分：S 或 A 加 6，B 加 4，C 加 2，D 加 0。
- 第三个独立来源加分：S 或 A 加 3，B 加 2，C 加 1，D 加 0。
- 总分封顶 25。没有合法等级时得 0，并记录缺口。

同一 `independence_group` 只保留最高等级。只有带 HTTP(S) 直达链接、位于窗口内且被至少一个评分维度引用的证据才进入来源质量分。

### 3. 价格验证：25 分

价格验证 = 证据形态（12）+ 已验证涨幅（5）+ 覆盖面（4）+ 持续性（4）。

证据形态：无信号 0；匿名传闻 1；调价意向/预测 3；供应商正式调价函或可验证报盘 6；公开价格指数/权威报价 9；成交、结算、合同或发票级证据 12。

已验证涨幅使用相同规格、地区和计价基础：`≤0%`、`0–<2%`、`2–<5%`、`5–<10%`、`≥10%` 分别为 0/1/3/4/5 分。

覆盖面按独立供应商、规格或地区数量：0/1/2/≥3 分别为 0/1/3/4 分。

持续性按可验证上涨天数：`≤1`、`2–3`、`4–7`、`≥8` 天分别为 0/1/3/4 分。

### 4. 供给约束：20 分

- 库存：无证据或正常 0；去库/低于季节性水平 3；历史低位、缺货或断供 5。
- 开工率或交期：正常 0；开工率上行或交期延长 3；接近满产、显著延长或排单紧张 5。
- 扰动/供给纪律：无 0；单点短期检修 1；多厂减产、检修、配额或出口限制 4；广泛或结构性约束 5。
- 需求/缺口：无 0；轶事线索 1；多来源订单或需求确认 3；量化供需缺口 5。

### 5. A 股异动：10 分

使用直接受益股等权篮子相对中证全指或等价宽基的监控窗口表现：

- 超额收益：`≤0%`、`0–<3%`、`3–<6%`、`6–<10%`、`≥10%` 得 0/1/2/3/4 分。
- 正超额收益广度：`<40%`、`40–<60%`、`60–<75%`、`75–<85%`、`≥85%` 得 0/1/2/2/3 分。
- 篮子成交额相对过去 20 日均值的中位倍数：`≤1`、`1–<1.3`、`1.3–<1.8`、`≥1.8` 得 0/1/1/2 分。
- 正超额收益天数：`≤1` 得 0 分，`≥2` 天得 1 分。

直接受益股少于 3 只时，把该项总分封顶为 5，并标记“低覆盖”。不要用间接受益股凑足篮子。

## 状态与硬门槛

| 总分 | 初始状态 |
|---:|---|
| 65–100 | 高确定性 |
| 50–64 | 发酵中 |
| 35–49 | 观察 |
| 0–34 | 证据不足 |

“高确定性”还必须同时满足来源质量 ≥15 且价格验证 ≥13。任何一项不满足时，状态降为“发酵中”，但保留原总分并写明门槛原因。

排序依次使用：总分降序、价格验证降序、来源质量降序、消息密度降序、材料名称升序。

## A 股映射

为每条材料列 2–5 家最相关公司，并标记“直接”或“间接”。说明产品、收入/利润暴露、产能或客户关系的证据。直接受益至少满足产品相关、涨价传导路径可解释、上市公司业务证据可验证；只有概念标签不得标为直接受益。

## 反证与缺口

至少检查价格回落、库存回补、复产扩产、进口替代、需求走弱、客户抵制涨价、替代材料、A 股高位透支等反证。把能够推翻结论的条件写成可观察事件。

任何缺失数据按 0 分处理。把接口失败、无权威报价、受益股不足、缺少价格序列、无法确认独立来源等逐项写入 `data_gaps`。
